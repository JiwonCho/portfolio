1. 포트폴리오 사이트 권장 페이지 구성
   대부분의 프런트엔드 포트폴리오는 원페이지(Single Page) 스크롤 방식이나 주요 메인 + 프로젝트 상세(Multi-Page) 방식을 채택합니다.

① Hero Section (메인 첫 화면)
목적: 3초 안에 직무, 정체성, 핵심 강점을 전달

구성 요소:

한 줄 정의 (예: "성능 최적화와 사용자 경험에 집중하는 3년 차 프런트엔드 개발자 OOO입니다.")

핵심 기술 스택 칩/태그 (React, TypeScript, Next.js 등)

주요 행동 유도 버튼 (CTA: "프로젝트 보기", "이력서 다운로드", "연락하기")

② About Me (소개 및 역량)
목적: 개발에 대한 철학과 문제 해결 역량 어필

구성 요소:

간단한 커리어 요약 및 개발 철학

보유 기술 스택 (기술을 단순히 열거하기보다 '사용 가능한 수준'을 명시)

예: React (컴포넌트 재사용성 향상 및 상태 관리 최적화 경험)

경력/학력/활동 타임라인

③ Projects (핵심 프로젝트 목록) — 가장 중요한 영역
목적: 실무 능력 및 문제 해결 과정 증명 (최대 3~5개 엄선)

각 프로젝트 카드 구성:

프로젝트명 및 한 줄 설명

대표 썸네일 (GIF나 동영상 시연 권장)

사용 기술 스택 (React, Tailwind, Redux 등)

핵심성과/트러블슈팅 요약 (예: Lighthouse 성능 점수 62pt → 94pt 개선)

링크 2개 (라이브 배포 링크 / GitHub 저장소 링크)

④ Project Detail Page or Modal (프로젝트 상세)
목적: 깊이 있는 기술적 고민과 트러블슈팅 서술

구성 요소:

개요 (기간, 참여 인원 및 기여도)

주요 구현 기능

트러블슈팅 (문제 상황 → 원인 분석 → 해결 방법 → 결과/배운 점)

아키텍처 구조도 또는 코드 하이라이트

⑤ Contact & Footer (연락처 및 하단)
목적: 손쉬운 채용/작업 제안 유도

구성 요소:

이메일, GitHub, 기술 블로그(Velog/Tistory/Medium), LinkedIn 링크

간단한 이메일 문의 폼 (Contact Form)
