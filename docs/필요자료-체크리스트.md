### 3-1. 프로젝트 화면 이미지 — 넣는 방법

카드 썸네일과 상세 페이지 갤러리(클릭 시 라이트박스)가 구현되어 있습니다.
데이터에 경로만 채우면 바로 뜨고, **없으면 해당 영역이 렌더되지 않습니다.**

**① 파일을 놓는다**

```
public/projects/usj-pass-domain/thumbnail.webp
public/projects/usj-pass-domain/01-pass-filter.webp
public/projects/usj-pass-domain/02-option-select-mo.webp
```

규격은 `public/projects/README.md` 참고. 요약하면:

| 용도 | 비율 | 권장 크기 | `ratio` |
| --- | --- | --- | --- |
| 카드 썸네일 | 16:9 | 1280 × 720 | — |
| PC 화면 | 16:9 | 1920 × 1080 | 생략 (기본 `wide`) |
| 모바일 화면 | 9:16 | 828 × 1472 | `'tall'` |

**② `projects.data.ts` 의 해당 프로젝트에 필드를 추가한다**

`metrics` 배열 아래에 넣으면 됩니다.

```ts
    thumbnail: '/projects/usj-pass-domain/thumbnail.webp',
    gallery: [
      {
        src: '/projects/usj-pass-domain/01-pass-filter.webp',
        alt: '아이 키·어트랙션·권종 조건을 고르는 「내게 맞는 패스 찾기」 필터 화면',
        caption: '조건을 고르면 일치도 점수로 패스를 재정렬한다',
      },
      {
        src: '/projects/usj-pass-domain/02-option-select-mo.webp',
        alt: '모바일 USJ 전용 옵션 선택 페이지',
        caption: '입장시간·추가옵션·비교함까지 한 페이지에서 처리',
        ratio: 'tall',
      },
    ],
```

`alt` 는 스크린리더용이니 "어떤 화면인지"를 문장으로, `caption` 은 "무엇을 보여 주는 장면인지"를
한 줄로 적어 주세요. 이미지 없이도 읽히던 내용이라 캡션이 설명을 대신하지 않아도 됩니다.

**③ 우선 넣으면 좋은 4건** (화면 제공 가능하다고 확인된 건)

| slug | 추천 장면 |
| --- | --- |
| `usj-pass-domain` | 맞춤 패스 필터 폼, 패스 비교함, 입장시간 선택 모달 |
| `group-product-in-page-booking` | 묶음상품 상세의 옵션 카드 레이어, MO 옵션 플로우 |
| `japan-bus-tour-soldout-alternative` | 매진일 선택 캘린더, 「예약 가능한 인기 상품 모음」 추천 블록 |
| `global-en-paypal` | 영문 상품상세, 게스트 예약 폼, PayPal 결제 시트 |

각 건당 **썸네일 1장 + 갤러리 2~3장**이면 충분합니다.

**④ 캡처 시 주의**

공개 서비스 화면이라도 아래는 가리거나 피해 주세요.

- 예약자 실명 · 연락처 · 이메일 · 주문번호
- 로그인된 회원 정보 (회원명, 등급, 포인트)
- 사내 관리자 · 어드민 화면, 결제 수단 정보

테스트 계정이나 더미 데이터 상태에서 캡처하는 편이 안전합니다.

> 나머지 12건은 이미지 없이도 **수치와 설계 판단만으로 성립**하도록 만들어 두었으므로
> 굳이 다 채우지 않아도 카드 정렬이 깨지지 않습니다.

## 4. 콘텐츠 판단이 필요한 부분

경력서 08 / Notes 에 적힌 한계가 사이트에도 그대로 적용됩니다.

- **사내 티켓 키(DT-, TPT-, RVYN-)는 전부 제외**했습니다. 외부 공개용이므로 근거 줄을 뺐습니다.
  면접용으로 필요하면 `Project` 타입에 `evidence: string[]` 를 추가해 되살릴 수 있습니다.
- **성과 지표가 비어 있습니다.** Jira 에는 전환율·응답 속도·검색 유입 같은 값이 없습니다.
  LCP 개선 전/후 수치, SEO 작업 후 색인/유입 변화, Lighthouse 점수를 확인해 넣으면
  프로젝트 상세의 설득력이 크게 올라갑니다. (`Project.metrics` 에 바로 추가 가능)
- **회사명·서비스명 노출 범위**를 확인해 주세요. 현재는 투어비스·프리비아·타이드스퀘어를
  그대로 쓰고 있고, 레포 이름과 파일 경로도 노출됩니다. 문제가 되면
  `projects.data.ts` 의 `repo` / `paths` 를 가리거나 제거하면 됩니다.

## 5. 배포

```bash
# Vercel
vercel                       # 또는 GitHub 연동 후 자동 배포
# 환경변수: WEB3FORMS_ACCESS_KEY
```

배포 후 `siteConfig.url` 을 실제 도메인으로 바꾸면 sitemap·canonical·OG 가 함께 따라갑니다.
