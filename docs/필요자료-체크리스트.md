## 3. 시각 자산

| 항목 | 위치 | 현재 상태 |
| --- | --- | --- |
| Favicon | `app/favicon.ico`, `app/icon.svg` | Next.js 기본 아이콘 — 교체 권장 |
| OG 이미지 | `app/opengraph-image.tsx` | **코드로 생성됨. 별도 파일 불필요** (문구만 수정 가능) |
| 프로젝트 썸네일 | `public/projects/{slug}.png` | 미사용. 넣으려면 `Project.thumbnail` 필드가 이미 타입에 있음 |
| 시연 GIF / MP4 | 동일 | 사내 서비스 화면이라 공개 가능 여부 확인 필요 |

> 프로젝트가 전부 **사내 서비스**라 스크린샷·시연 영상은 회사 자산일 가능성이 높습니다.
> 현재 카드/상세는 **수치와 설계 판단**으로만 구성해 이미지 없이도 성립하도록 만들었습니다.
> 공개 가능한 화면이 있다면 썸네일을 추가하는 쪽이 더 좋습니다.

## 4. 콘텐츠 판단이 필요한 부분

경력서 08 / Notes 에 적힌 한계가 사이트에도 그대로 적용됩니다.

- **사내 티켓 키(DT-, TPT-, RVYN-)는 전부 제외**했습니다. 외부 공개용이므로 근거 줄을 뺐습니다.
  면접용으로 필요하면 `Project` 타입에 `evidence: string[]` 를 추가해 되살릴 수 있습니다.
- **성과 지표가 비어 있습니다.** Jira 에는 전환율·응답 속도·검색 유입 같은 값이 없습니다.
  LCP 개선 전/후 수치, SEO 작업 후 색인/유입 변화, Lighthouse 점수를 확인해 넣으면
  프로젝트 상세의 설득력이 크게 올라갑니다. (`Project.metrics` 에 바로 추가 가능)
- **회사명·서비스명 노출 범위**를 확인해 주세요. 현재는 투어비스·프리비아·타이드스퀘어를
  그대로 쓰고 있고, 레포 이름과 파일 경로도 노출됩니다. 문제가 되면
  `projects.data.ts` 의 `repo` / `paths` 를 가리거나 제거하면 됩니다.
