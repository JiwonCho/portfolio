# 프로젝트 화면 이미지

`src/entities/project/model/projects.data.ts` 의 `thumbnail` / `gallery` 가 참조하는 파일을 둔다.

## 폴더 규칙

```
public/projects/{slug}/
  thumbnail.webp        카드 대표 이미지 (16:9)
  01-<설명>.webp        갤러리 1번
  02-<설명>.webp        갤러리 2번
```

`{slug}` 는 `projects.data.ts` 의 `slug` 값과 같게 한다.

## 규격

| 용도 | 비율 | 권장 크기 | ratio 값 |
| --- | --- | --- | --- |
| 카드 썸네일 | 16:9 | 1280 × 720 | — |
| PC 화면 | 16:9 | 1920 × 1080 | `'wide'` (기본값) |
| 모바일 화면 | 9:16 | 828 × 1472 | `'tall'` |

- 포맷은 **WebP** 권장 (PNG/JPG 도 동작하며 Next.js 가 자동 변환한다)
- `next/image` 가 리사이즈·lazy loading·포맷 변환을 처리하므로 원본을 그대로 넣으면 된다
- 파일 하나당 1MB 이하를 권장한다

## 캡처 시 주의

공개 서비스 화면이라도 아래는 가리거나 피한다.

- 예약자 실명 · 연락처 · 이메일 · 주문번호
- 로그인된 회원 정보 (회원명, 등급, 포인트)
- 사내 관리자 · 어드민 화면
- 결제 수단 정보

테스트 계정이나 더미 데이터 상태에서 캡처하는 편이 안전하다.
